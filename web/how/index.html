How it is built

The technology, in plain words.

arcroad runs on open maps, open code and a small amount of cloud computing. No cameras, no sensors, no paid data and nothing to install. Here is every piece, explained for someone who has never written code.

The map

OpenStreetMap

A free map of the world that anyone can edit, a bit like Wikipedia for roads. Every road, median and U-turn opening in Hyderabad that arcroad studies comes from it.

Read with an open tool called osmium, which turns the raw map file into roads the code can work with.

Working out the way round

arcroad's own route code

Code that walks the road network the way a law-abiding driver must: only legal turns, only the allowed direction. It finds how far you really drive to reach the point straight across.

Written in Python, a popular programming language, with the number libraries pandas, NumPy and SciPy. Think of a very large spreadsheet that recalculates the same way every time.

Checking our own answer

OSRM and Valhalla

Two independent, free route engines used by map apps around the world. We ask both for the same trips; if they agree with us within 10%, the trip is confirmed. Like asking two other people with maps.

18 of the 20 Hi-Tech City loop trips agree. The 2 that do not are shown, not hidden.

Buses

GTFS bus timetables

A standard file format that bus operators use to publish routes and stops. It lets arcroad work out how far a bus, and everyone on it, is sent round.

Used by the bus part of the loop check, for TGSRTC routes.

Proving it on the road

Phone GPS and photos

The model's answers were driven and recorded with a phone's GPS. Photos show what the driver saw. Faces and number plates are blurred before anything is published, and raw GPS never is.

Results on the driven results page; routes, start points and times are never published.

Pre-flight checks

Automatic tests

Over 300 small automatic checks run before every update, like a pilot's checklist. If one fails, nothing goes live.

Run on every change, on the computer and again in the cloud.

A record of every change

Git and GitHub

Git keeps a history of every edit, so any version can be brought back. Each saved version gets a short code called a commit, like a receipt number. A public open copy lives on GitHub.

The poster's code version, b04e705, is one such receipt: anyone can rerun it and get the same numbers.

The website

Cloudflare Pages

Copies of the site are kept in data centres around the world, so the page loads from somewhere near you, quickly and safely.

Every page you are reading. No cookies, no tracking.

Small server tasks

Functions and KV storage

A function is a tiny program that runs only when needed, for example when someone signs up as a volunteer. KV storage is a simple locker system: each entry has a numbered key and a small value.

Volunteer sign-ups keep only an area, the choices made and a random code. No names, emails or phone numbers.

Heavy work on a timer

Containers and batch jobs

A container is a sealed lunchbox: the program plus everything it needs, so it runs the same anywhere. A batch job is work that starts by itself on a schedule, like a washing machine on a timer.

arcroad's research runner is a container that wakes up on a schedule, runs the long calculations and switches itself off.

Where results are kept

R2 cloud storage

Storage for files in the cloud, like a shared drive. The scheduled runner drops its finished results there, ready to be checked before anything is published.

Nothing goes from there to this site on its own: results are checked first.

Maps on your screen

MapLibre

A free, open tool that draws interactive maps in the browser, so you can zoom and pan without any paid map service.

Used on the globe and the map views. No Google Maps data is used anywhere.

Telling the original from a copy

Fingerprints and timestamps

Each original file gets a fingerprint: a short code computed from its contents, which changes if even one comma changes. Public timestamp authorities then stamp when that fingerprint existed, like a notary's seal.

So anyone can check that the published files are the originals and when they were made.

What we do not use

  • No Google Maps data, and no paid map or traffic data.
  • No cookies, no tracking scripts, no visitor tracking.
  • No hardware on the road, and nothing a city has to buy or install.
